# Tuneup docs

Tuneup is the settings app Omarchy is missing: screens and desktops, window look, desktop widgets, sound, camera, minimizing windows, and Galaxy Book support. It lives in the tray. Two commands come with it: `tuneup` for everything (`hypr-screens` still works as an alias) and `hypr-minimizer`, which the minimize keys call.
